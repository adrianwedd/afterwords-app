# Security Policy

## Reporting a vulnerability

Email adrianwedd@gmail.com with subject "SECURITY: afterwords-app".
You'll get an acknowledgement within 72 hours. Please don't open public
issues for security reports.

## Distribution posture (honest version)

Release DMGs are currently unsigned and un-notarized — verify the SHA-256
in the release notes before opening (see RELEASING.md "Current
distribution reality"). Auto-updates ARE verified: Sparkle EdDSA
signatures over an HTTPS feed, with monotonic version enforcement.

## Supported versions

The latest release on the appcast.
