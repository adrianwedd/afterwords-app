## Task 1 — Rasterise the app icon

**Context:** `afterwords-icon.svg` is already at the repo root. `rsvg-convert` produces clean anti-aliased PNGs from SVG. The geometry of the SVG is locked for this sprint (lower oval `ry=92`); do not edit the SVG. The `make test` suite must pass after this task.

**Files:**
- Create: `Afterwords/Assets.xcassets/AppIcon.appiconset/icon_*.png` (10 files)

- [ ] **Step 1: Install rsvg-convert**

```bash
which rsvg-convert || brew install librsvg
rsvg-convert --version
```

- [ ] **Step 2: Create the output directory**

```bash
mkdir -p Afterwords/Assets.xcassets/AppIcon.appiconset
```

- [ ] **Step 3: Rasterise all sizes**

```bash
for size in 16 32 128 256 512; do
  rsvg-convert -w $size        -h $size        afterwords-icon.svg \
    -o "Afterwords/Assets.xcassets/AppIcon.appiconset/icon_${size}x${size}.png"
  rsvg-convert -w $((size*2)) -h $((size*2)) afterwords-icon.svg \
    -o "Afterwords/Assets.xcassets/AppIcon.appiconset/icon_${size}x${size}@2x.png"
done
```

- [ ] **Step 4: Verify all ten files exist and are non-empty**

```bash
cd Afterwords/Assets.xcassets/AppIcon.appiconset
ls -la icon_*.png | awk '{print $5, $9}'
```

Expected: 10 lines, all sizes > 0 bytes. Smallest should be around 300B (16×16), largest around 60KB (512×512@2x).

- [ ] **Step 5: Spot-check smallest and largest**

```bash
file Afterwords/Assets.xcassets/AppIcon.appiconset/icon_16x16.png
file Afterwords/Assets.xcassets/AppIcon.appiconset/icon_512x512@2x.png
```

Expected: `PNG image data, 16 x 16` and `PNG image data, 1024 x 1024`. Inspect the 16×16 and 32×32 manually to verify both comma glyphs are visible as separate shapes and the lower glyph is taller than wide (portrait teardrop). If the glyphs merge into a blob at 16×16, the 16×16 slot is acceptable to ship as-is for now — the 32×32 is the practical minimum for legibility.

## Task 7 — Add GitHub Actions Pages deploy workflow

**Context:** GitHub Pages deployment via Actions requires the repo Pages setting to be "GitHub Actions" (not the `docs/` branch/folder source — those two modes are mutually exclusive). This workflow deploys only when `docs/` changes.

**Files:**
- Create: `.github/workflows/pages.yml`
- Modify: `.github/workflows/ci.yml`

- [ ] **Step 1: Create the Pages deploy workflow**

Create `.github/workflows/pages.yml`:

```yaml
name: Deploy GitHub Pages

on:
  push:
    branches: [main]
    paths:
      - 'docs/**'
  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: pages
  cancel-in-progress: false

jobs:
  deploy:
    runs-on: ubuntu-latest
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    steps:
      - uses: actions/checkout@v4
      - uses: actions/configure-pages@v5
      - uses: actions/upload-pages-artifact@v3
        with:
          path: docs/
      - id: deployment
        uses: actions/deploy-pages@v4
```

- [ ] **Step 2: Add Pages asset verification to CI**

Open `.github/workflows/ci.yml`. After the existing test step, add:

```yaml
      - name: Verify GitHub Pages assets
        run: |
          test -f docs/index.html         || (echo "ERROR: docs/index.html missing" && exit 1)
          test -s docs/index.html         || (echo "ERROR: docs/index.html is empty" && exit 1)
          test -f docs/favicons/og-app.png || (echo "ERROR: docs/favicons/og-app.png missing" && exit 1)
          test -s docs/favicons/og-app.png || (echo "ERROR: docs/favicons/og-app.png is empty" && exit 1)
          echo "GitHub Pages assets: OK"
```

- [ ] **Step 3: Enable GitHub Pages in repository settings (manual)**

Go to https://github.com/adrianwedd/afterwords-app/settings/pages and set:
- Source: **GitHub Actions**

This is a manual one-time step. If Pages was previously configured to deploy from a branch/folder, change it to Actions. The deploy workflow will not run until this is set.
